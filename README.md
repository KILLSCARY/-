# Покоритель P2P 3.0 — игра для Telegram Mini App

3D-раннер к курсу «Покоритель P2P 3.0». Крыс в белом сомбреро и с цепью «7.0» бежит ночью по мокрому
району между панельками, собирает USDT и уворачивается от препятствий.

## Управление

| Действие | Телефон | Клавиатура |
|---|---|---|
| Сменить полосу | свайп влево/вправо | ← → / A D |
| Прыжок (через мусорные баки) | свайп вверх | ↑ / W / пробел |
| Подкат (под «БЛОК») | свайп вниз | ↓ / S |
| Пауза | ⏸ | Esc / P |

Тачки едут навстречу: их можно только объехать. Золотая монета «×2» удваивает USDT на 8 секунд.
Очки = USDT × 10 + метры.

## Запуск локально

Сборка не нужна, это чистые HTML, CSS и ES-модули. Three.js r149 и постобработка (bloom) лежат в `js/vendor`, потому что CDN в РФ бывают недоступны.
Текстуры асфальта, плитки, бетона и металла взяты с [Poly Haven](https://polyhaven.com) (CC0) и лежат в `textures/`.

```bash
python3 -m http.server 8000
# открыть http://localhost:8000
```

Вне Telegram всё работает на заглушках: рекорд сохраняется в localStorage.

## Структура

```
index.html        экраны: меню, HUD, пауза, проигрыш
css/style.css     оформление
js/config.js      ссылки (бот, курс), баланс, тексты смертей и подсказок
js/game.js        состояние игры, управление, камера, коллизии
js/world.js       улица, панельки, дождь, препятствия, монеты, спавн
js/rat.js         модель крыса из примитивов и анимации
js/audio.js       синтезированные звуки и бит
js/tg.js          Telegram WebApp: expand, haptics, CloudStorage, share
```

## Подключение к Telegram

1. Залить папку на любой статический хостинг с HTTPS: GitHub Pages, Vercel, Netlify или Cloudflare Pages.
2. В @BotFather: `/newbot`, затем `/newapp`, выбрать бота и указать URL игры.
3. В `js/config.js` вписать `LINKS.bot` (ссылку `t.me/<бот>/<app>`) и `LINKS.course`.
