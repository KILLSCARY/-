# Дубай на закате

Дубай заменяет Нячанг у Димы и Саши. Для любого героя его можно включить через
«Настройки → Локация → Дубай · закат» или ссылкой `?location=dubai`.
«По герою» возвращает выбор по персонажу. Сохранения, баланс, сбор монет,
препятствия и сюжетные события продолжают использовать существующую механику.
Внутренние `vietnam`, `VIETNAM` и экспорт `Vietnam` сохранены для совместимости.

Окружение: сухой бульвар, каменная набережная и вода, стеклянные высотки,
магазины, пальмы с изогнутыми листьями и подсветкой стволов, скамьи, урны,
клумбы и припаркованные Corvette из существующей облегчённой модели.
Вдали расположены ступенчатая башня со шпилем и отель с силуэтом паруса —
стилизованные ориентиры Дубая, без претензии на точную копию архитектуры.
Закатное небо, солнце и облака рисуются в фоновую текстуру при смене размера
экрана или локации. Туман 65–275 м, дальность камеры 320 м на всех уровнях.
Материалы ориентиров не растворяются в тумане.

Пять блоков по 32 м переиспользуются во время забега; геометрия каждого
объединена по материалам. Дальний город неподвижен. Текстура фасада
`textures/dubai/facade-v1.webp` (1024×1024, около 183 КБ) подготовлена специально
для локации: стекло, бронзовые рамы, отражения и тёплые интерьеры. Карты общие
для зданий; до загрузки доступна процедурная замена. Пальмы, камень и асфальт
получают небольшие процедурные текстуры. Новых источников света, отражающей
камеры, дождя и анимированных волн нет; WebGL и сглаживание сохранены.

Проверки (при работающем статическом сервере на 8001):

```sh
node --test tests/*.test.mjs
PLAYWRIGHT_MODULE=/opt/codex/cua_node/lib/node_modules/playwright node tests/dubai.browser.cjs
PLAYWRIGHT_MODULE=/opt/codex/cua_node/lib/node_modules/playwright node tests/winter.browser.cjs
```

Проверяются запуск забега, сбор монет, движение препятствий, повторение блоков,
выбор и сохранение локации, совместимость маршрутов героев, переключение сцен,
все уровни качества и ошибки WebGL. Снимки: `/tmp/dubai-mobile.png` и
`/tmp/dubai-desktop.png`. Мобильный профиль Chromium проверяет интерфейс и
рендеринг; FPS и нагрев нужно измерять на настоящем телефоне.
