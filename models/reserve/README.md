# Запас моделей и текстур

Игра эти файлы не загружает. Это проверенные бесплатные ассеты на будущее. Их можно посмотреть на стенде «Лаборатория ассетов».

Лицензия у всех — CC0 1.0: можно в коммерции, указывать автора не нужно.

Перед тем как ставить в игру:
- Рост задавать по габаритам с учётом скелета. Сырой рост у людей 0,15 м, у корги — сотни единиц.
- Копии делать через `SkeletonUtils.clone`, обычный `.clone()` ломает скелет.
- Модели смотрят в +Z.
- Кости названы случайно, это не mixamorig. Наши клипы на них не переносятся, оружие крепить по положению кости.
- Стиль низкополигональный, «игрушечный», с нашими моделями Meshy не сочетается.
